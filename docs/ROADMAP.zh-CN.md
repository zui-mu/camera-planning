# 阶段路线与验收条件

> 0.4 更新：自由空间观测域、加权下尾部质量、多起点选择、自适应增量证据、覆盖 Lazy/MILP 基线、缓存重选、开放避障路径已接入。当前未完成布局与路径联合优化、全程目标可见性硬约束、真实网格整房验证与真实 HMR 对照。详见 [新版说明](ROBUST_PLANNING.zh-CN.md)。以下保留原阶段记录。

## P0 — 已完成：外置工程闭环

已实现：严格规划输入、AABB 与三角网格 BVH 查询、目标家具表面与确定性构图包络、家具局部 OBB 候选生成、距离/画幅/遮挡过滤、可见性/分辨率/投影信息量、固定预算选择与基线、Blender/常见交换格式导入、超大场景代理、冻结快照、相机预览与采集、RQ1 分组、相机并集复用、重复集合去重、显式场景常量控制、下游命令计划与人工确认执行器、MHR 关节指标、JSON/CSV 汇总及测试。

尚未完成的东西不写成已实现：reference 解码/材质恢复、真实资产的 RQ1 全链运行、论文统计结果、拓扑核验后的顶点指标、后端感知学习模型、生成视频评测和连续运镜。

## P1 — 真正跑通一个可信的 RQ1

优先级最高，不建议先训练 RL。

- 把真实场景的米制世界几何与 reference 对应 mesh 固定到一个版本。
- 将现有 scene adapter 与 mesh/BVH 查询用于真实资产，并人工检查导出对象、单位和允许区域；AABB 仅保留为基线。
- 检查 reference mesh/joints 与渲染世界坐标；先验证少量图的 SAM3D 检测与恢复是否可用。
- 固定 B 和候选池，共享单视角估计，独立做各子集融合。
- 明确固定或实测 scene_consistency，不混用语义。
- 使用现有结构化结果汇总；继续补 body-only 关节列表、拓扑验证的顶点误差和论文级统计。

验收：能展示同一 reference 在不同布局下的图片、融合人体、差异指标、失败日志及版本记录。成功标准是实验可信，而不是第一天必须胜过所有基线。

## P2 — 从工程原型变成可研究方法

先消融“仅家具表面”“仅构图包络”“两者联合”，检验完整人物构图约束是否真正改善下游；再消融包络余量、完整身高、相机距离、画面边缘、遮挡精度、像素尺度、视角互补和信息项。主方法不再引入站、坐、躺的位置概率。

检验跨家具/场景/人体泛化，报告候选密度、预算、K、渲染材质敏感性。如果几何代理与后端偏差弱相关，可以用训练集上的实际回环误差学习轻量 set ranking/残差校准模型。先从可解释特征回归或排序开始，不必第一版就用大网络。

验收：在独立测试场景上，能回答哪个设计改善了什么；能解释失败场景；计算开销与简单均匀/随机/覆盖基线同表报告。

## P3 — 回到完整 YSynthetic 生成管线

加入图像/视频生成的固定预算实验，记录 camera matching 可用率、相机漂移、有效视角数、姿态共识及融合有效率。使用真实 scene_consistency，不采用 RQ1 常量控制。

如果视频生成要求运动相机，再增加独立 trajectory module：在静态集合上选择访问顺序、考虑允许空间和速度/曲率约束，生成密集 pose sequence，并检查插值期间碰撞与构图。静态相机好不等于连接路径可行。

LLM 交互提示是可选上游条件；若纳入，需要另开有提示与无提示设置，不能改变主论文的信息假设而不说明。

验收：证明 controlled round-trip 的收益至少部分转移到实际生成链，或明确指出迁移瓶颈。不是只有渲染干净人体的理想条件结果。

## P4 — 正式并入

保持 artifacts 和字段版本；将核心规划器作为轻依赖库；在 YSynthetic 增加薄 workflow/CLI、配置、文档和集成测试。只有得到修改主项目的授权后再做。本次保持外置。

## 最大风险与对应策略

| 风险 | 当前处理 / 后续动作 |
| --- | --- |
| 构图包络过大或过小 | 把 clearance、完整身高和画幅边缘作为显式约束与消融变量，不称为人物概率 |
| AABB 错误地遮挡空洞/椅腿 | 真实入口已换三角 mesh/BVH；保留 AABB 只作基线，并继续做射线可视检查 |
| 模型不识别无纹理参考人 | 先单视角验证渲染域；材质固定为独立实验变量 |
| 后端近似单视角主导 | 记录 active/used views、权重、共识，不把有效 B 当名义 B |
| 几何分数与网络误差无关 | 先验证再加复杂度；允许删掉无用项或做后端校准 |
| 参考自身偏差 | 称 round-trip consistency；之后增加独立真值/合成真值基准 |
| 视频不同帧姿态不同 | RQ1 冻结姿态；RQ3 单独量化，不声称天然同步 |
| 算力/时间超预算 | 少量候选、逐图推理、缓存严格版本；先 pilot 再扩大 |
| 新颖性不足 | 重点比较直接人体布局工作；把未知未来人体与后端适配的增量做实 |
